CSS Text Alignment

The text-align Property

The text-align property is used to set the horizontal alignment of a text.

This property can have one of the following values:

  • left - Aligns the text to the left
  • right - Aligns the text to the right
  • center - Centers the text
  • justify - Stretches the lines so that each line has equal width

Example: Different Text Alignments

h1 { text-align: center; } h2 { text-align: left; } h3 { text-align: right; }

Text Align Justify

When the text-align property is set to "justify", each line is stretched so that every line has equal width, and the left and right margins are straight (like in magazines and newspapers).

Example: Justify Alignment

div { text-align: justify; }

Text Align Last

The text-align-last property specifies how to align the last line of a text.

This property can have the following values:

  • auto - Default. The last line is justified and aligned left
  • left - The last line is aligned to the left
  • right - The last line is aligned to the right
  • center - The last line is center-aligned
  • justify - The last line is justified

Vertical Alignment

The vertical-align property sets the vertical alignment of an element.

Common values include:

  • baseline - Default. Aligned with the baseline of the parent
  • top - Aligned with the top of the tallest element on the line
  • middle - Placed in the middle of the parent element
  • bottom - Aligned with the lowest element on the line
  • sub - Aligned with subscript baseline
  • super - Aligned with superscript baseline

Example: Vertical Alignment

img.top { vertical-align: top; } img.middle { vertical-align: middle; } img.bottom { vertical-align: bottom; }

Text Direction

The direction property specifies the text direction/writing direction within a block-level element.

Tip: Use the direction property together with the unicode-bidi property to set or return whether the text should be overridden to support multiple languages in the same document.
