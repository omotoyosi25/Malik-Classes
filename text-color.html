CSS Text Color

What is the color property?

The color property is used to set the color of the text. This is one of the most basic and commonly used CSS properties.

How to Specify Colors

The color can be specified in three main ways:

  • Color name - like "red", "blue", "green"
  • HEX value - like "#ff0000", "#0000ff"
  • RGB value - like "rgb(255, 0, 0)"

Example: Basic Text Colors

body { color: blue; } h1 { color: green; } h2 { color: red; }

This is body text in blue color

This is an h1 heading in green

This is an h2 heading in red

Text Color and Background Color

You can combine text color with background color to create various designs. However, always ensure good contrast for readability!

Example: Text and Background Colors

body { background-color: lightgrey; color: blue; } h1 { background-color: black; color: white; } div { background-color: blue; color: white; }
Important: High contrast is very important for people with vision problems. Always ensure that the contrast between the text color and the background color is good!

Good vs Bad Contrast

✓ Good contrast: Black text on white background is easy to read
✗ Bad contrast: Grey text on light grey background is hard to read
