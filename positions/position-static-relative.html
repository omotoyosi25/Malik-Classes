Static & Relative Positioning

CSS position: static

All HTML elements are positioned static by default.

Static positioned elements:

  • Follow the normal document flow
  • Are NOT affected by the top, bottom, left, and right properties
  • Are NOT considered "positioned" elements
  • Stack according to their order in the HTML

An element with position: static; is always positioned according to the normal flow of the page.

Example: Static Position (Default)

div.static { position: static; border: 3px solid #73AD21; }
This <div> element has position: static;
Note: Since static is the default position value, you rarely need to explicitly set position: static; unless you're overriding a different position value.

CSS position: relative

An element with position: relative; is positioned relative to its normal position in the document flow.

Key characteristics of relative positioning:

  • The element remains in the document flow
  • Its original space is preserved (other elements don't move)
  • You can use top, right, bottom, left to offset it from its normal position
  • The element is considered "positioned" (important for absolute positioning)

Example: Relative Position

div.relative { position: relative; left: 30px; border: 3px solid #73AD21; }
This <div> has position: relative and is moved 30px to the right from its normal position
Important: Setting the top, right, bottom, and left properties will cause the element to be adjusted away from its normal position. Other content will NOT be adjusted to fit into any gap left by the element.

How Other Elements Are Affected

When you use relative positioning, the element moves but its original space remains reserved. Other elements behave as if the relatively positioned element is still in its original location.

Example: Multiple Elements with One Relative

.box-1 { background: red; } .box-2 { background: green; position: relative; left: 30px; top: 10px; } .box-3 { background: blue; }
Box 1 (static)
Box 2 (relative - moved 30px right, 10px down)
Box 3 (static - notice it doesn't move up to fill the space)

When to Use Relative Positioning

Use Case 1: As a Container for Absolute Elements

Relative positioning is often used to create a positioning context for absolutely positioned child elements (we'll cover this in the next lesson).

Use Case 2: Minor Adjustments

Use relative positioning when you need to nudge an element slightly from its normal position without affecting the layout of surrounding elements.

Use Case 3: Z-Index Control

Relative positioning allows you to use the z-index property to control stacking order.

Comparison: Static vs Relative

Feature position: static position: relative
Default? Yes No
In document flow? Yes Yes (space reserved)
Affected by offset properties? No Yes
Considered "positioned"? No Yes
Can use z-index? No Yes
