Sticky Positioning

CSS position: sticky

An element with position: sticky; toggles between relative and fixed position, depending on the scroll position.

A sticky element is positioned relative until a certain scroll position is reached - then it "sticks" in place (like position: fixed).

How Sticky Positioning Works

Sticky positioning behaves in three phases:

  • Phase 1 (Before threshold): Acts like position: relative; - stays in normal document flow
  • Phase 2 (At threshold): "Sticks" to specified position - acts like position: fixed;
  • Phase 3 (After parent boundary): Scrolls away with its parent container
Important: You must specify at least one of top, right, bottom, or left properties for sticky positioning to work. This defines the threshold where the element becomes "stuck".

Example: Basic Sticky Element

div.sticky { position: sticky; top: 0; background-color: green; border: 2px solid #4CAF50; }

In this example, when the sticky element reaches the top of the viewport (top: 0), it sticks to that position.

Common Use Cases for Sticky Positioning

1. Sticky Headers

Navigation bars or section headers that stick to the top when scrolling.

2. Sticky Sidebars

Side content (like a table of contents) that stays visible while scrolling main content.

3. Sticky Table Headers

Table headers that remain visible when scrolling through long tables.

4. Sticky Call-to-Action Buttons

Important buttons that stick in view while users scroll through content.

Pro Tip: Sticky positioning respects parent boundaries. Once the parent container scrolls out of view, the sticky element goes with it. This is different from fixed positioning, which always stays relative to the viewport.

Sticky vs Fixed Comparison

Feature position: sticky position: fixed
Initial behavior Acts like relative Always fixed to viewport
Space in document Takes up space initially Does not take up space
Scroll behavior Sticks after threshold Always fixed
Container bound Yes, respects parent boundaries No, always relative to viewport
Offset property required Yes (top, bottom, left, or right) Optional

Exercise

Question: What is required for position: sticky to work?

  • At least one of top, bottom, left, or right must be set ✓
  • The element must have a positioned ancestor
  • The element must be inside a fixed container
  • The element must have a specific height

Question 2: How does sticky positioning differ from fixed positioning?

  • They work exactly the same way
  • Sticky doesn't work in modern browsers
  • Sticky respects parent boundaries; fixed does not ✓
  • Fixed requires offset properties; sticky does not
