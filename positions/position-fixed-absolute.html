Fixed & Absolute Positioning

CSS position: fixed

An element with position: fixed; is positioned relative to the viewport, which means it always stays in the same place even if the page is scrolled.

Key characteristics of fixed positioning:

  • Positioned relative to the browser viewport
  • Does NOT move when the page is scrolled
  • Removed from the normal document flow
  • Does NOT leave a gap in the page where it would normally be
  • Uses top, right, bottom, left to set its position

Example: Fixed Position

div.fixed { position: fixed; bottom: 0; right: 0; width: 300px; border: 3px solid #73AD21; }
Live Demo: Look at the bottom-right corner of your screen. There's a fixed orange box that stays in place even when you scroll this page!

Common Uses for Fixed Positioning

  • Fixed navigation bars at the top of the page
  • Floating action buttons
  • Chat widgets
  • Cookie consent banners
  • Back to top buttons

CSS position: absolute

An element with position: absolute; is positioned relative to the nearest positioned ancestor (an ancestor with position set to anything other than static).

Key characteristics of absolute positioning:

  • Positioned relative to its nearest positioned ancestor
  • If no positioned ancestor exists, it uses the document body
  • Removed from the normal document flow
  • Can overlap other elements
  • Moves with page scrolling (unless ancestor is fixed)
Important: Absolute positioned elements are removed from the normal document flow, and can overlap other elements. Other elements behave as if the absolutely positioned element doesn't exist.

Example: Absolute Position with Relative Parent

div.relative { position: relative; width: 400px; height: 200px; border: 3px solid green; } div.absolute { position: absolute; top: 80px; right: 0; width: 200px; height: 100px; border: 3px solid red; }

Positioning Text On an Image

A very common use case for absolute positioning is placing text overlays on images. The image container is set to position: relative; and the text elements are set to position: absolute;

Example: Text Overlays on Image

.image-container { position: relative; } .text-overlay { position: absolute; background: rgba(0, 0, 0, 0.7); color: white; padding: 10px; } .top-left { top: 10px; left: 10px; } .top-right { top: 10px; right: 10px; } .bottom-left { bottom: 10px; left: 10px; } .bottom-right { bottom: 10px; right: 10px; } .centered { top: 50%; left: 50%; transform: translate(-50%, -50%); }

Understanding Positioned Ancestors

For absolute positioning, a "positioned ancestor" is any parent, grandparent, or higher-level ancestor element that has its position property set to relative, absolute, fixed, or sticky (anything except static).

Pro Tip: The most common pattern is to set a parent container to position: relative; (without any offset properties) just to create a positioning context for absolutely positioned children.

Comparison: Fixed vs Absolute

Feature position: fixed position: absolute
Positioned relative to Viewport Nearest positioned ancestor
Affected by scrolling? No Yes (moves with ancestor)
In document flow? No No
Takes up space? No No
Common uses Fixed navbars, modals Dropdowns, tooltips, overlays
