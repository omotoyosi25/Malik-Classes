CSS Combinators

What are CSS Combinators?

A combinator is something that defines the relationship between two or more selectors.

A CSS selector can contain more than one selector. Between the selectors, we can include a combinator to create a more specific selection.

The Four CSS Combinators

There are four different combinators in CSS:

  • Descendant combinator (space)
  • Child combinator >
  • Next sibling combinator +
  • Subsequent-sibling combinator ~

Descendant Combinator (space)

The descendant combinator matches all elements that are descendants (children, grandchildren, great-grandchildren, etc.) of a specified element.

Example: Descendant Combinator

Select all <p> elements inside <div> elements:

div p { background-color: yellow; }

Paragraph 1 in the div (will be yellow)

Paragraph 2 in the div (will be yellow)

Paragraph 3 inside section inside div (will be yellow)

Paragraph 4 outside the div (will NOT be yellow)

Key Point: The descendant combinator selects ALL descendants at ANY level, not just direct children.

Child Combinator (>)

The child combinator selects all elements that are direct children of a specified element.

Example: Child Combinator

Select all <p> elements that are direct children of <div>:

div > p { background-color: yellow; }

Paragraph 1 in the div (direct child - will be yellow)

Paragraph 2 in the div (direct child - will be yellow)

Paragraph 3 inside section (NOT direct child - will NOT be yellow)

Paragraph 4 outside the div (will NOT be yellow)

Descendant (space)

div p { }

Selects ALL <p> elements inside <div> at any level

Child (>)

div > p { }

Selects ONLY direct <p> children of <div>

Next Sibling Combinator (+)

The next sibling combinator selects an element that is directly after a specific element.

Sibling elements must have the same parent element.

Example: Next Sibling Combinator

Select the first <p> element that immediately follows a <div>:

div + p { background-color: yellow; }
This is a div

Paragraph 1 immediately after div (will be yellow)

Paragraph 2 (will NOT be yellow)

Another div

Paragraph 3 immediately after second div (will be yellow)

Important: The + combinator only selects the FIRST element immediately after the specified element.

Subsequent-sibling Combinator (~)

The subsequent-sibling combinator selects all elements that are next siblings of a specified element.

Example: Subsequent-sibling Combinator

Select all <p> elements that are next siblings of <div>:

div ~ p { background-color: yellow; }

Paragraph 1 before div (will NOT be yellow)

This is a div

Paragraph 2 after div (will be yellow)

Paragraph 3 after div (will be yellow)

Section between paragraphs

Paragraph 4 after div (will be yellow)

Next Sibling (+)

div + p { }

Selects ONLY the first <p> immediately after <div>

Subsequent-sibling (~)

div ~ p { }

Selects ALL <p> elements that come after <div>

Exercise

Question: Which combinator selects elements that are direct children of a specified element?

  • Child combinator (>) ✓
  • Descendant combinator (space)
  • Next sibling combinator (+)
  • Subsequent-sibling combinator (~)

CSS Combinators Summary

Combinator Symbol Description
Descendant (space) Selects all descendants at any level
Child > Selects direct children only
Next Sibling + Selects the first element immediately after
Subsequent-sibling ~ Selects all siblings that come after
